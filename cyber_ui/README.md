# Cyberpunk UI Shell (Pygame + pygame_gui)

This folder is a standalone, sleek UI shell you can plug your simulation into later.

## Install

From repo root (recommended in a venv):

```bash
python -m pip install -r m.i.n.d/cyber_ui/requirements.txt
```

## Run

```bash
python3 m.i.n.d/cyber_ui/main.py
```

## Controls

- `ESC`: quit
- UI buttons: run/pause/reset
- Telemetry chart + stats update automatically with mock data
